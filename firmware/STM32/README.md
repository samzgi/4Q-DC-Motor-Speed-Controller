# STM32 Firmware

This directory is reserved for the STM32 firmware source code used by the four-quadrant DC motor controller.

Expected content may include:

- PWM generation and complementary switching logic
- Dead-time / shoot-through protection logic
- Motor direction control
- Encoder speed measurement
- ACS712 current measurement
- Current-limit protection
- Soft-start routine
- OLED interface

Firmware source files will be added when the final STM32 project files are organized.
